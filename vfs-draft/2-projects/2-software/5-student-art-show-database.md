# Student Art Show Database

*High school, 2024 – 2025*

Websites for St. Anne's-Belfield's All-School Visual Art Show, where artwork is searchable by student name, year or course.

### What I built
* **SAS (team site, 2024):** I was the top contributor. It has search with recommendations and history, a page per student, and CSV import into Firebase.
* **SVDB (solo, 2025):** the "Saints Virtual Database", a rebuild with case-insensitive search and a CSV upload page on Firestore.

### Tech
* JavaScript, HTML, CSS
* Firebase Firestore
* GitHub Pages
