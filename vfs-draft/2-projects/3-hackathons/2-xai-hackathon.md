# xAI Hackathon

*Invite-only, 30+ teams, Dec 2025*

Two tools built at the hackathon:

* **Recruiting analyzer:** uses computer vision (optical flow) to analyze how a person works on their computer, then generates a competency report.
* **Onboarding course generator:** an LLM app that turns Markdown documents into interactive onboarding courses.

### Tech
* Computer vision, optical flow
* LLMs, NLP
