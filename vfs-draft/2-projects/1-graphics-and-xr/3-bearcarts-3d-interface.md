# BearCarts 3D Interface

*Solo concept for the WashU delivery robot, Sep 2026*

A 3D proof-of-concept app for BearCarts, the campus food-delivery robot built by WashU Robotics and WashU's Google Developer club. Every screen is printed onto a model of the robot itself.

### What I built
* The home screen lives on the robot's underside, with store cards riding a looping tread belt.
* Orders appear on the lid, and the robot rolls over to show them. Settings sit inside the cargo bay.
* The robot's proportions follow the screen's aspect ratio, so it fits phones and desktops.
* Mock store and order data, ready for the planned GrubHub integration.

### Tech
* React 19
* three.js, React Three Fiber
* zustand
* Vite, Docker
